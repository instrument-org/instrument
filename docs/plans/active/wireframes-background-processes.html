What the agent left running

A task can end with a server or watcher still running. Today nothing says so and quitting the app is the only way to stop one. Four places that could carry it, then the interaction for the one worth building.

The word process never appears. Every frame says still running, because the audience is someone who did not ask for a server and does not know they have one.

Where it could live

A Above the prompt input
2 things still running

Sits where the user already looks before typing, and survives scrolling. Costs a permanent strip of vertical space next to the one control everything else defers to.

B Inline in the transcript
Still running
node work/server.js

Twenty minutes later this is a thousand pixels up the scroll.

Truthful at the moment it is written and wrong from then on. A transcript is a log, and this is live state, so it is the one place the fact cannot stay correct.

C Task header
Helsinki launch site 2

Always visible and costs nothing when the count is zero. Also the quietest thing on screen: a 2 in a pill next to a title is not a sentence anyone reads.

D Sidebar
Helsinki launch site

The only option that shows a task you are not looking at.

Answers a question none of the others can: which of my other tasks left something running. Too small to stop anything from, so it is a companion to A, not a rival.

A, opened and used

1 Resting
2 things still running

One line, one verb. A user who does not care can ignore it forever and it never asks a question.

2 Opened
2 things still running
Web server on port 8123
node work/server.js · 41m
Rebuilding on every change
pnpm dev · 41m

A plain-language line above the command, so the user is not asked to read pnpm dev to know what they are stopping. Naming it is the only hard part of this design.

3 Stopped
Both stopped

The strip is gone, not emptied. Nothing running means nothing on screen, so the surface only ever exists when it has something to say.

The two states nobody designs for

Stopped by the two-hour cap
The web server was stopped after 2 hours. Ask to start it again if you still need it.

The cap is a good idea that looks like a bug if it happens silently. Dismissible, and it says what to do next.

Gone after a restart

Nothing survives a quit, so the strip is simply absent. The user needs no notice; the agent does, and that is a context problem rather than a UI one.
