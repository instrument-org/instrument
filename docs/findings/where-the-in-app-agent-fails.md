# Where the in-app agent fails

**Status:** measured on 2026-10-12 over real chats and eval runs from 2026-10-01 to then; open. The virtual-path class has since been removed by real host paths, and the browser layout-shift click is fixed; the rest stands.

Which failures of the product's own agent cost the most, from its stored chats and its eval runs. Real chats: 96 sessions, 209 user messages, 792 model steps and 751 tool calls, 77 of them failed (10.3%). Evals: 1,853 transcripts in 1,024 runs, 13,338 steps and 12,306 tool calls, 779 failed (6.3%); 63% of eval calls came from one day's build between two agent designs, so results are split before and after it where that matters. A failure is an error state, a non-zero shell exit, or a tool result that reports failure; error text was normalized (paths, numbers, ids) and grouped. A "repair loop" is the next call repeating the same command. Recovery cost is the next step's input tokens, an approximation that is mostly cache reads. No turn ended at the step limit in the window.

## Ranking, by frequency times cost

| # | Source | Where | Measure | Example error (normalized) | Change |
|---|---|---|---|---|---|
| 1 | Virtual paths: commands refused a folder mount, files not found at mount paths | evals mostly | 76 refusals in 48 sessions; a refused command run again as-is failed 20 times out of 26; of 91 file-not-found errors, 66 were at mount paths; a call naming a mount path failed 9.9% of the time against about 5% otherwise; about 26k tokens per recovery step | `python: <P> is inside an attached folder, which python cannot read` | removed: the agent works at real host paths |
| 2 | Browser: clicks refused, stale refs, CDP timeouts | real chats | 24 of 251 browser calls failed, in 9 of the 17 sessions that browsed; clicks failed 16% (12 of 75), snapshots 12.5%; repeating the same click succeeded 3 of 3; about 64k tokens per recovery step | `The click was not sent: the page's layout shifted after the element was measured` (5), `Element <ref> is covered by <…>` (3), `Unknown ref` (2) | layout shift fixed (the press goes to where the element settled); "covered by" has no retry upstream and no fix here |
| 3 | Provider errors that end a turn | both | real: a spent weekly limit (3 steps in one chat), one 503, one model fetch failure; evals: 180 HTTP 500s in 24 sessions on the ChatGPT account route, all "Cannot construct a Request with a Request object that has already been used", and 462 credit-exhausted 429s on the eval account | `Cannot construct a Request with a Request object that has already been used` | reproduce the Request reuse on the current route; make a spent limit a named stop with its reset time instead of retries |
| 4 | The PDF skill checker's rules | evals | 126 checker failures in 75 sessions; 25 sessions took two to five rounds and about 29 never passed; about 42k tokens per round, roughly 5M in all; rules hit: empty band 101, page count 29, prose-heavy 22, stranded 19, no hero 13 | `empty-band` | give each rule a concrete amount to change, or relax empty band under a page; lives in the skills repo |
| 5 | AppleScript and macOS access | real chats | 11 of 19 `osascript` calls failed (58%), all in two mail and messages chats on one model | `syntax error: Expected class name but found identifier` (3, AppleScript mixed with JavaScript for Automation), `Application isn't running` (3) | launch the app before scripting it, and a working example in the Mail guide; the native helper and the permissions list cover the rest |
| 6 | Cheap tool fixes | evals | a first browser call guessing a command (13: `tabs` 6, `profiles` 4, `connect` 3); a screenshot into a missing folder; `rg` or `grep` exiting 1 with no match shown as an error (86, after which the next search failed 28 of 34 times); 23 tool inputs meant for another tool | `Failed to save screenshot to <P>: No such file or directory` | alias `tabs` and list the commands in the unknown-command error; create parent folders; say "no matches"; name the tool the input was meant for |

Already gone in the window: `task new` versus `task fork` churn on the one transitional build (105 failures, 3 of 40 in real chats after it), and the chat shell's allowlist refusals (25, some refusing commands that were fine), removed on 2026-10-07.

Lower volume: `web_fetch` 403, 404 and timeouts (21, rarely retried), edit-file string-not-found or multiple-match (12, usually fixed in one step), tool timeouts (4).
