# Plans

Execution plans for non-trivial work, checked in so an agent (or human) can pick
them up later with full context. One Markdown file per plan.

- `active/` — plans not yet finished. Each starts with a `Status:` line.
- `completed/` — finished or abandoned plans. Move them here with `Status:`
  updated rather than deleting, so the rationale stays legible; link the PR or
  commit that carried the work.

Add a `tech-debt-tracker.md` here if a running list of known debt becomes useful.
